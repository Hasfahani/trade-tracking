This model flags unusual trades. It does not guarantee profit.

What the score means. The model estimates how unusual an observed trade is versus the wallet's own prior history, from behavioral and contextual signals only (trading pace, timing gaps, market focus, price extremity, the wallet's past outlier rate). It is an anomaly score, not a profit forecast, and it is not calibrated to a probability — treat a high score as "worth a look", not a guarantee. Reported metrics are point estimates on a single temporal split and will move as more data arrives.

Label definition. A training row is positive when the observed trade value is unusually large versus that wallet's prior value history. To avoid leakage, the production model excludes the current trade's own value, value ratio, and value z-score, so it learns surrounding behavior rather than rediscovering the label rule.

Lecture baseline

Single sigmoid neuron, MSE loss, and an epoch loop with gradient updates.

Production version

Same single-sigmoid idea, but trained with binary cross-entropy and class weighting because notable trades are rare.

Why not plain MSE?

With an imbalanced label, the MSE sigmoid baseline can settle into predicting the majority class and miss rare notable trades.
